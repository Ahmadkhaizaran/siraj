# سِراج — إدارة التعليم في المساجد والمراكز

منصّة عربية بواجهة RTL لإدارة الجهات التعليمية والحلقات والمعلمين والطلاب، ومتابعة الحضور وحفظ القرآن والتقييمات. تشمل حسابات الطلاب، سبع رتب تحفيزية، ترتيب الطلاب والجهات، شهادات قابلة للمشاركة والطباعة، مراسلات خاصة وتعاميم وإشعارات معزولة حسب الصلاحيات، ومصحف حفص، وثيم فاتح وداكن.

## الاستضافة الحالية

- **الرابط المباشر:** https://siraj-black.vercel.app — تسجيل الدخول بحساب سِراج من دون الحاجة إلى حساب ChatGPT.
- **المصدر:** https://github.com/Ahmadkhaizaran/siraj
- **Vercel / Next.js:** الواجهة وواجهات API على نفس النطاق.
- **Supabase Edge Function `siraj-api`:** منطق الصلاحيات والحسابات وعمليات قاعدة البيانات.
- **Supabase PostgreSQL:** عشرون جدولاً في مخطط `siraj` الخاص. RLS مفعّل، ولا وصول مباشر من المتصفح.
- **GitHub:** المصدر، دون بيانات المستخدمين أو مفاتيح التشغيل.

يحتفظ المشروع بمسار تشغيل Cloudflare/D1 الأصلي للتوافق. النسخة الجديدة لا تستخدم بوابة التحويل القديمة في `deployment/vercel`، ولا تعتمد على ChatGPT لتسجيل الدخول.

## الإعداد

```sh
pnpm install --frozen-lockfile
pnpm build:vercel
```

متغيرات Vercel التالية **خاصة بالخادم فقط** وتُضبط كقيم مشفّرة، ولا تضاف إلى Git:

| المتغير | الغرض |
|---|---|
| `SIRAJ_BACKEND_URL` | عنوان دالة Supabase `siraj-api` |
| `SIRAJ_BACKEND_KEY` | مفتاح خادم عشوائي؛ يتحقق الطرف الآخر من SHA-256 الخاص به |
| `SIRAJ_PASSWORD_PEPPER` | سر مستقل لتجزئة كلمات المرور؛ يجب الحفاظ عليه |
| `SIRAJ_SETUP_TOKEN_HASH` | تجزئة مفتاح إعداد المالك للقاعدة الجديدة فقط |

طبّق `deployment/supabase/001_siraj_schema.sql` مرة واحدة على مخطط جديد. جهّز حزمة الخلفية عبر:

```sh
SIRAJ_BACKEND_KEY_HASH=<sha256-of-backend-key> node deployment/supabase/build-edge.mjs
```

ارفع `outputs/supabase-edge/index.js` كدالة Supabase باسم `siraj-api`. تتحقق الدالة من مفتاح الخادم بنفسها؛ لا تفعّل JWT الخاص بـSupabase أمام هذا المسار. تستخدم `SUPABASE_DB_URL` المتاح في بيئة الدالة، ولا تعرض SQL عامًا أو مفاتيح قاعدة البيانات للمتصفح.

## الحسابات المنقولة

نُقلت سجلات المنصة الأصلية إلى Supabase. سر كلمات المرور القديم يبقى في الاستضافة الأصلية. عند أول تسجيل دخول صحيح لحساب منقول، تتحقق الخلفية مرة واحدة من حسابه لدى الموقع الأصلي عبر HTTPS، ثم تعيد تجزئة كلمة المرور بالسر الجديد وتلغي علامة النقل. الحسابات الجديدة وكلمات المرور المعدلة تُتحقق محليًا.

تتطلب عملية النقل رد JSON صريحًا بقيمة `ok: true`. صفحات تسجيل الدخول ونتائج الخادم غير المتوقعة لا تُعتمد تحققًا ناجحًا، ويظهر تعذّر التحقق بدل رسالة كلمة سر خاطئة عند انقطاع المصدر. إذا تغيّرت كلمة السر أو أُوقف الحساب أثناء انتظار الرد، لا تنشأ جلسة اعتمادًا على كلمة السر القديمة.

يجب إبقاء الموقع الأصلي `https://siraj.ahmadkh28.chatgpt.site` متاحًا حتى تنتقل الحسابات أو يعيد أصحاب الصلاحية تعيين كلمات مرورها. البيانات ليست متزامنة باستمرار بين الاستضافتين؛ استخدم الرابط الجديد للعمل بعد النقل. ملفات البيانات وكلمات المرور والجلسات ليست ضمن هذا المستودع.

## الصلاحيات

مدير المنصة يدير الجهات وفريق المنصة. مشرف المنصة يدير الجهات والتعاميم والدعم مع تقييد إدارة فريق المنصة بالمالك. المشرف الأساسي يدير جهته وفريقه، والمدرس يتابع الحلقات المسندة إليه، والطالب يرى ملفه وتقدمه. تسجيل الدخول مستقل باسم مستخدم وكلمة مرور، مع جلسات HttpOnly والتحقق من المصدر للطلبات المعدلة.

## التحقق

```sh
node tests/integration.mjs
node tests/assistant-unit.mjs
node node_modules/typescript/bin/tsc --noEmit
```

تغطي مجموعة التكامل 408 فحوصات. لتشغيل نفس الاختبارات على PostgreSQL معزول باستخدام PGlite، ثبّت `@electric-sql/pglite@0.3.14` محليًا في بيئة الاختبار، ثم:

```sh
SIRAJ_TEST_DATABASE=postgres PGLITE_MODULE_PATH=/absolute/path/to/pglite/dist/index.js node tests/integration.mjs
```

لا تشغّل مجموعة الاختبار على قاعدة الإنتاج. تشمل الفحوصات عزل الجهات وصلاحيات المدرّسين، الحضور، تقييمات القرآن، النقاط والرتب، التعميم، الإشعارات وإلغاء الحسابات. العمليات المجمّعة في PostgreSQL تنفذ ضمن معاملات ذرية.

للتحقق من نقل كلمات المرور على قاعدة اختبار معزولة:

```sh
PGLITE_MODULE_PATH=/absolute/path/to/pglite/dist/index.js node tests/password-migration.mjs
```

ولفحص الرابط المنشور من دون حساب أو تعديل بيانات المستخدمين:

```sh
node scripts/verify-deployment.mjs https://siraj-black.vercel.app
```

يتحقق الفحص من الصفحات والملفات الأساسية واتصال قاعدة البيانات ومنع الوصول إلى البيانات الخاصة من دون تسجيل الدخول. لا يغني ذلك عن تسجيل دخول فعلي بحساب منقول. النشر الحالي مباشر؛ ربط GitHub من إعدادات Vercel مطلوب لتفعيل النشر التلقائي عند كل تحديث.
