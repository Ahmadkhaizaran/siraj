# Siraj typography

UI: IBM Plex Sans Arabic 400/500/600/700. Headings: Tajawal 700/800. Quran: existing Amiri Quran unchanged. Credentials: monospace unchanged. Self-hosted WOFF2, font-display swap, no external font requests. Original font files obtained from google/fonts ofl/ibmplexsansarabic and ofl/tajawal; the corresponding OFL licenses are distributed alongside them. Lossless WOFF2 conversion via fontTools/Brotli.

Preview: /typography-preview shows previous/current text, light/dark samples, Arabic/Latin numerals, fields and rank badge. Base text 16px, supporting text 14px, fields 16px, headings 700/800. Arabic letter-spacing remains zero. Certificates now use IBM Plex Sans Arabic, loaded before canvas export.
