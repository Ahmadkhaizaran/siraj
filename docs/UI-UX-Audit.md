# سراج — مراجعة الواجهة والهوية والصلاحيات

التاريخ: ٥ تشرين الثاني ٢٠٢٦. النطاق: مراجعة المصدر، تطبيق نظام تصميم مشترك، فحوص تكامل محلية وفحص النشر. هذه مراجعة عملية وليست اختبار اختراق شاملًا أو شهادة توافق WCAG.

## النتائج والإصلاحات

| الأولوية | الملاحظة | التعديل |
|---|---|---|
| عالية | تفاصيل واجهة ٩–١٢ بكسل وألوان باهتة في مكوّنات أساسية | رفع النص الأساسي إلى ١٥، الحقول ١٦، التفاصيل الرئيسية ١٣، لون مساعد أكثر وضوحًا |
| عالية | النوافذ القديمة لا تحصر Tab داخلها ولا تعيد التركيز | مدير مشترك يحصر Tab وShift+Tab، يختار حقلًا أوليًا، يعيد التركيز ويوقف تمرير الصفحة الخلفية |
| عالية | درجات التركيز في الداكن ضعيفة | إطار تركيز ذهبي ظاهر، مع الإبقاء على أسماء الحقول |
| متوسطة | أحجام أزرار وأيقونات غير متناسقة | أزرار ٤٦، أهداف أيقونات ٤٤، حواف ومسافات موحدة |
| متوسطة | ضغط شريط الأدوات والنماذج بالموبايل | التفاف الأدوات، هوامش ١٦، نموذج قابل للتمرير وحقول ١٦ لمنع تكبير iOS التلقائي |
| متوسطة | الحركة لا تراعي تفضيل تقليل الحركة | تعطيل الانتقالات والحركات غير اللازمة عند تفعيل reduced-motion |
| متوسطة | التنقل المتكرر عبر القائمة قبل المحتوى | رابط تجاوز للمحتوى مع هدف قابل للتركيز |
| متوسطة | تشتيت بصري وتفاوت العناوين والبطاقات | طبقة تصميم واحدة بعد ثيم الداكن، خطوط عربية دون تضييق حروف، حدود وظلال هادئة |
| متوسطة | غياب إعدادات حماية متصفح صريحة في إعداد Next | منع تضمين الموقع بإطار، nosniff، سياسة إحالة، تعطيل صلاحيات كاميرا وميكروفون وموقع غير مستخدمة |
| فحص | اختبار التقويم يعتمد يومًا ثابتًا انتهى | جعل موعد حدث الاختبار موافقًا لليوم في بيروت؛ لم يتغير منطق التقويم الإنتاجي |

## الهوية المسلّمة

الحفاظ على أيقونة سراج الحالية، مع نظام أخضر عميق وذهبي وعاجي. الدليل يشمل الجوهر والنبرة، نسخ الشعار ومساحة الأمان والحد الأدنى، الألوان واستخدامها، الخطوط والتراخيص، المسافات والمكونات، قواعد الصور والزخارف، الموبايل والداكن، تطبيقات اجتماعية ومراسلات. ملفات SVG قابلة للتحرير، الخط مضمّن في التطبيقات، مع ملفات الخط وتراخيصها.

## المراجعة الأمنية والوظيفية

المصدر يستخدم جلسات HttpOnly وSecure على HTTPS وSameSite=Strict، ويرفض طلبات التعديل من أصل مختلف. التحقق من الصلاحيات في الخادم لا يعتمد على إخفاء عناصر الواجهة. فحوص التكامل تغطي عزل الجهات، حسابات الفريق والطلاب، تعيين الحلقات، الحضور وتراكم النقاط وتصحيحها، وتعارض الكتابة. هذه التغييرات لا تعدّل بيانات الإنتاج أو قواعد التقييم.

لم تُجرَ محاولات اختراق أو تحميل هجومي على الإنتاج. لم يُطلب أو يُكشف أي سر تشغيل أو كلمة مرور. لم تُنشأ حسابات أو علامات تجريبية في قاعدة الإنتاج.

## حدود المراجعة والمتابعة

- النمط المشترك يشمل الصفحات الرئيسية والحسابات والنماذج والجداول، لكنه لا يساوي اختبارًا بصريًا لكل سجل ولكل دور على جهاز فعلي.
- يلزم اختبار قارئ شاشة فعلي وVoiceOver على iPhone، وتكبير ٢٠٠٪ مع بيانات طويلة.
- الجداول الطويلة والتقارير الكبيرة تحتاج قياس أداء ببيانات واقعية قبل اعتماد pagination أو virtualization؛ لم يُغيّر مسارها اعتباطيًا.
- توجد ألوان قديمة في مكوّنات فرعية؛ لا يشمل هذا التسليم ضمان نسبة تباين لكل تركيب لوني. الألوان الأساسية الجديدة مصممة لقراءة أوضح، والذهبي لا يُستخدم كنص صغير فوق الأبيض.
- المصادقة المتعددة العوامل، سياسات النسخ الاحتياطي واستعادته، واختبار استرجاع الحسابات تحتاج مراجعة تشغيلية مستقلة.
- المعاينة المحلية أعلنت التشغيل لكن المتصفح أعاد connection refused. لم تُستبدل البنية أو إعدادات الشبكة لتجاوز المشكلة. التحقق البصري المحلي غير مكتمل؛ تعتمد مراجعة النسخة المنشورة على الجلسة المتاحة فقط.

## نتائج التحقق قبل النشر

- نجح TypeScript والبناء الإنتاجي لـNext.js بعد فصل تشغيل المعاينة عن البناء لتجنّب تعارض الملفات المولّدة.
- نجحت ٥٠١ عملية تحقق API على قاعدة D1 محلية معزولة، تشمل الصلاحيات والحلقات والحسابات.
- نجحت اختبارات إرشاد المساعد، بيانات المصحف (١١٤ سورة و٦٢٣٦ آية)، وتقويم بيروت وتكرار النشاطات والمراجع الحديثية.
- لا توجد تغييرات على مخطط القاعدة أو قواعد النقاط في هذه الدفعة.
